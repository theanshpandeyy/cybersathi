# 🛡️ CyberSathi — Your Digital Safety Companion

> **Be Aware. Be Secure.**

A modern cybersecurity awareness platform that helps users **identify, understand, and respond to online threats** through interactive learning, scam scenarios, threat analysis, and cybersecurity assessments.

## ✨ Features

| Module | Description |
|---|---|
| 🔍 **ThreatCheck** | Analyze suspicious URLs, SMS, WhatsApp messages, and emails |
| 🧠 **ScamSense** | Practice identifying realistic scam scenarios |
| 📚 **CyberGuide** | Learn about common cybersecurity threats and safety practices |
| 🛡️ **ShieldScore** | Test cybersecurity awareness through an interactive assessment |
| 📊 **Live Statistics** | View real platform activity and awareness statistics |

---

## 🎯 Objective

CyberSathi aims to:

- Increase awareness of phishing, scams, and digital fraud
- Help users recognize common warning signs
- Encourage safer digital habits
- Improve cybersecurity decision-making

> **Think before you click, share, pay, or trust.**

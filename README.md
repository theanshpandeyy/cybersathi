🛡️ CyberSathi — Your Digital Safety Companion

A modern cybersecurity awareness platform designed to help users identify phishing, online scams, and digital fraud through interactive learning, real-world scenarios, threat analysis, and practical safety guidance.

📌 About the Project

CyberSathi is a cybersecurity awareness platform focused on increasing awareness about common digital threats such as phishing, online scams, social engineering, fake websites, malicious links, OTP fraud, payment scams, job scams, QR scams, and social media fraud.

The platform provides simple and interactive educational experiences instead of overwhelming users with complex cybersecurity concepts.

Users can:

Analyze suspicious URLs, messages, WhatsApp messages, and emails
Identify realistic scam scenarios
Learn about common cybersecurity threats
Test their cybersecurity awareness
Receive practical safety recommendations
Track awareness activity through live platform statistics

The primary goal is to encourage users to think before they click, share, pay, or trust.

🎯 Project Objectives

The project aims to:

Increase awareness of phishing, scams, and digital fraud
Help users recognize common warning signs
Demonstrate real-world scam scenarios
Improve cybersecurity decision-making
Encourage safer digital habits
Provide practical cybersecurity guidance
Assess users' cybersecurity awareness

🗄️ Database

CyberSathi uses PostgreSQL to store non-sensitive learning and project activity.

Main Tables
users

Stores anonymous participant information.

threat_checks

Stores threat analysis results.

scenario_attempts

Stores ScamSense scenario attempts.

quiz_attempts

Stores completed ShieldScore assessments.

quiz_answers

Stores individual ShieldScore answers.

The platform uses anonymous participant IDs and avoids collecting unnecessary personal information.

🔐 Privacy & Security

CyberSathi follows a minimal-data approach.

The platform does not require users to provide sensitive information such as:

Passwords
OTPs
UPI PINs
Card numbers
Bank credentials
Aadhaar numbers
Authentication secrets

The platform is designed for cybersecurity education and awareness rather than collecting personal information.

🚀 Getting Started
Prerequisites

Make sure you have installed:

Node.js
npm
Python 3.10+
PostgreSQL
Git
Clone the Repository
git clone https://github.com/theanshpandeyy/cybersathi.git
cd cybersathi
Frontend
cd cybersathi-frontend
npm install
npm run dev
Backend
cd cybersathi-backend
python -m pip install fastapi uvicorn sqlalchemy psycopg2-binary python-dotenv
python -m uvicorn app.main:app --port 8001
